# Glosaniko — локальная главная

Запуск: `npm start`, адрес: http://127.0.0.1:4187. Зависимости не требуются. Также можно открыть index.html напрямую.

Основной источник требований: проектно-техническая документация, раздел 7.1. Сохранены все 11 блоков. По правкам пользователя каталог расположен перед системой компонентов. Надзаголовки и точки в заголовках удалены. Фирменные цвета: серый #5B5B5B, жёлтый #FECC00. Логотипы и рендеры — из предоставленной клиентом папки Яндекс Диска. Arial — временный системный шрифт, отдельный фирменный шрифт не предоставлен.

Текущий объём: только главная будущего многостраничного сайта. Переходы во внутренние разделы в локальном макете показывают уведомление. После создания страниц обработчик data-preview снимается; адреса переходов уже заданы. Меню, якоря и диалог работают с клавиатуры. Добавлены переключение компонентов, раскрываемые этапы окраски, анимация появления карточек и реакции на наведение с учётом prefers-reduced-motion. Пиктограммы маркетплейсов — стилизованные обозначения, не исходники официальных логотипов.

Плейсхолдеры: согласованные выкрасы и названия цветов, отзывы, данные о производстве, B2B-условия, контакты и реальные ссылки на магазины. Цветовые образцы не имитируют ассортимент. Технические параметры не придуманы. Отзывы из папки ещё не сверены и не публикуются автоматически.

Форма демонстрационная: данные не отправляются и не сохраняются. Перед запуском подключить отправку на email клиента и добавить согласованные юридические тексты. Нет корзины, цен, оплаты, регистрации и интеграций. До публикации заменить/скрыть все временные значения, сверить контент и ссылки.

Проверка синтаксиса: `npm run check`. Публичный просмотр — GitHub Pages из корня основной ветки. Это версия для обсуждения, с временным контентом и демонстрационной формой.

Для следующих страниц сохранять текущую стилистику: контрастный первый экран, фирменный жёлтый #FECC00 и серый #5B5B5B, серые продуктовые карточки с крупными банками и фасовкой, геометрические акценты, читаемый основной текст, заголовок и подзаголовок последовательно. Надзаголовки и точки в заголовках не использовать. Требования и пользовательские сценарии брать из проектно-технической документации; новые факты не придумывать.


Главная обновлена по согласованному направлению «Цвет в действии»: постановочная иллюстрация поверхности, короткие закреплённые сцены, анимация композиции. Движение отключается при prefers-reduced-motion; на телефоне компоненты идут последовательно. Обработчик скролла использует кэш геометрии и обновляет только элементы в области просмотра. Изображения для главной — оптимизированные WebP. Фактические исходники упаковки сохранены. Старую главную можно восстановить из истории Git; homepage-previous.html — локальная резервная копия.


Обновление арт-дирекции: общий site-art.css и облегчённый site-art.js применены ко всем готовым внутренним страницам. Главный баннер прокручивается обычным способом: закрепление, исчезновение текста, увеличение фона и банки при скролле отключены. Скролл-сцена компонентов и анимация появления остальных блоков сохранены.


Отзывы: страница `/reviews/`, записи в `reviews/data.json`. Поле `type` принимает `text` или `image`; `visible: false` скрывает запись. Имя, текст, дата, оценка и оттенок перенесены из семи скриншотов клиентской папки «Отзывы». Неизвестные оценки/даты не выводятся. Оригиналы сохранены в `assets/reviews/`; увеличение доступно для обоих форматов. Площадка не подписана конкретным брендом, поскольку источник не указан отдельными ссылками. Для добавления отзыва достаточно добавить запись и исходное изображение; новые отзывы требуют материалов клиента. Формы самостоятельной публикации отзывов нет.
«Где купить» в шапке — кнопка раскрытия, самостоятельной страницы нет. Пункты ведут к существующим блокам продавцов и маркетплейсов главной.
Обновление отображения отзывов: для обоих типов всегда показывается полный текст в единой карточке. Скриншот — компактное вложение только для записей type=image; увеличение без внешних ссылок. На десктопе ряды одинаковой высоты, на мобильном — естественная высота текста.

Актуальный объём: главная, каталог продукции, четыре категории (/products/enamels/, /products/hardeners/, /products/thinners/, /products/kits/), образцовая детальная страница эмали, каталог цветов и карточка Баклажановый 107, инструкция, о бренде, отзывы, сотрудничество, /dealers/, /marketplaces/, /contacts/. «Где купить» раскрывает меню двух страниц. Контакты предоставлены клиентом. Карточка цвета: изображение из папки первого слайда Яндекс, артикул BCPRO2038 и EAN 4673747343684 из клиентской таблицы. Остальные выкрасы, технические PDF, продавцы и прямые ссылки маркетплейсов ожидаются. Формы остаются демонстрационными. Служебные страницы пока не разрабатывались.

Раздел сотрудничества теперь /dealers/: B2B-преимущества из ТЗ, четыре карточки пользы, три шага, форма имя/телефон и контакты. /partners/ перенаправляет на /dealers/. Поиск продавца перенесён на /where-to-buy/, доступен из раскрывающегося меню «Где купить». Гарантии поставок, наличие в сезон и условия поддержки не заявлены без подтверждения.

Главная: точечная смысловая очистка с сохранением 11 блоков, hero и механики motion-runtime. Карточки продукции и CTA сотрудничества ведут на готовые разделы. Отзывы на главной: подтверждённые оценки и исправленная пунктуация без изменения смысла. Итоговый CTA /#contacts — визуал из существующих упаковок и поля имя/телефон. Локальные стили homepage-refinement.css не затрагивают внутренние страницы. Отправка формы остаётся демонстрационной.

Финальный CTA главной: полноширинный адаптивный фон feedback-surface.webp (mobile-версия 800 px), форма поверх изображения. Блок сотрудничества светлый. Фон создан встроенным image_gen: постановочный крупный план графитового кузовного металла с жёлтым отражением, без упаковки, логотипов и текста; не является фотографией реальной работы с продуктом.

Privacy UI: два самостоятельных обязательных чекбокса без отметок по умолчанию (согласие на обработку данных, ознакомление с политикой). Документы /privacy/ и /consent/ — рабочие проекты, требуют реквизитов и уточнения обработки до запуска. Формы по-прежнему демонстрационные. Уведомление хранит только факт закрытия в localStorage; аналитика не подключена. При переносе на Тильду проверить cookies и gating счётчиков отдельно. Пиктограмма Яндекс Маркета получена из favicon_194x194 официальной страницы market.yandex.ru (07.10.2026), без перерисовки.
