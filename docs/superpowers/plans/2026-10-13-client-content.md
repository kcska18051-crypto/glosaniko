# Перенос клиентского контента Glosaniko

**Цель:** перенести правки из карты текстов и клиентского макета без изменения утверждённой визуальной системы. Пользователь разрешил изменения состава блоков; «Где купить» остаётся без изменений.

**Подход:** локальный клиентский HTML сверяется с картой текстов. Переносится содержимое основных блоков с сохранением актуальной шапки, подвала, CSS, JS, фонов и навигационных адресов. Изменения структурных контейнеров проверяются на совместимость с текущими анимациями. Изображения/иконки/масштаб упаковок остаются прежними до отдельного согласования.
