# Где купить — данные и редактирование

Источник: клиентская таблица «Дилеры GLOSANIKO.xlsx», получена через Google Drive 12.10.2026.
https://docs.google.com/spreadsheets/d/1_Bhz8uFehaF21fpm3kgBRYPmm-5opuwV/edit

Исходные строки сохранены в `data/dealers-source.csv`; рабочие данные — `assets/dealer-network.json`.
89 регионов, 19 назначений, 7 уникальных дилеров. Названия сохранены дословно.

## Редактирование

- `dealers`: одна запись на компанию. `id` — постоянный ключ, `name` — название. `visible: false` скрывает дилера и показывает маркетплейсы во всех его регионах.
- `regions`: `name` — исходное название региона; `dealerId` — ключ компании либо `null`. Изменение `dealerId` меняет привязку без дублирования компании.
- Контакты дилера: `address`, `phone`, `website`, `logo`, `shopUrl`. Пока значения `null`: ничего не выводится. Заполнять только подтверждёнными данными. `shopUrl` выводит кнопку магазина, `website` — отдельную ссылку на сайт.
- `marketplaces`: три официальные площадки; `url` — подтверждённая витрина Glosaniko. Сейчас ссылки не предоставлены, поэтому переходов нет. После заполнения кнопки появятся в обоих блоках автоматически.

Данные загружаются из локального статического JSON, без интеграций с Google Drive, CRM, 1С или API площадок. Для Tilda HTML, CSS, JS и JSON должны быть перенесены совместно; пути к JS и JSON адаптируются к размещению. Живой синхронизации с таблицей нет.

## Поведение

`/where-to-buy/` — единая страница. Якоря `#marketplaces` и `#dealer-search`.
`/marketplaces/` перенаправляет на `/where-to-buy/#marketplaces`, старые ссылки не теряются.
`/dealers/` остаётся отдельной B2B-страницей «Сотрудничество».
Выбор стандартный HTML select, алфавитная сортировка `localeCompare(..., 'ru')`, результат обновляется без перезагрузки. До выбора компании нет. При отсутствии/скрытии дилера — маркетплейсы. Карта не используется.

## Проверено 12.10.2026

Сверены все названия и назначения с исходным CSV. В браузере последовательно выбраны все 89 регионов: 19 правильных дилерских результатов, 70 результатов без карточки дилера, в каждом выбранном регионе три площадки. Проверены ширины 320, 390, 768 и 1440 px, отсутствие горизонтального скролла, начальное состояние, корректность навигации и сохранение B2B-раздела.

Незавершённая часть: реальные внешние переходы на маркетплейсы ожидают подтверждённых ссылок клиента. Контакты компаний также отсутствуют в исходной таблице.
